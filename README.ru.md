# Alyx Turnip

**Модифицированный драйвер Mesa Turnip для автономного VR-проекта Alyx Jailbreak.**

**Русский** · [English](README.md) · [Инструкция сборки](docs/BUILD.md#русский) · [Происхождение исходников](docs/PROVENANCE.md)

Alyx Turnip объединяет наши изменения совместимости с Quest, исправления
рендеринга, отдельные обновления Mesa, работу с FDM/VRS и оптимизации
процессорной части компилятора шейдеров в вариантах драйвера Android ARM64.
Доступны прежний вариант совместимости, MSAA2/VRS и тестовый вариант с кэшем
итоговой карты. Особенности импорта изображений и OpenXR обрабатывает приложение.

Это независимый производный проект, а не официальный выпуск Mesa, Meta,
PICO, Qualcomm или Valve.

## Что входит

- **Исправления рендеринга и памяти:** очистка и сохранение FDM-вложений,
  ограничение области очистки, сброс и синхронизация командных буферов,
  обработка ошибок выделения памяти и отправки команд.
- **Сокращение повторной работы:** повторное использование состояния
  шейдеров, бинарного кода и загрузок для binning.
- **Выбранные исправления Mesa:** viewport/scissor, GMEM fences, владение
  данными дескрипторов, запросы бюджета памяти и улучшения IR3/NIR.
- **Опциональный перевод FDM в аппаратный VRS** для подходящих проходов A7xx.
  `compat` поддерживает проходы без MSAA; `msaa-vrs` добавляет MSAA 2x,
  разрешение цвета/глубины и допустимые размеры блоков затенения до 4x2.
  В самом драйвере режим выключен по умолчанию и включается приложением.
- **Кэш итоговой VRS-карты** в `msaa-vrs-cache` учитывает число сэмплов и
  убирает повторное ограничение карты MSAA при попадании в кэш. Вариант тестовый.
- **Оптимизация CPU-компилятора:** PGO, ThinLTO и настройки Cortex-A78C
  для отдельных библиотек компилятора, ускоренные пути анализа диапазонов,
  переиспользование временных SSA-наборов и отложенная компиляция вариантов
  с безопасной длиной констант.

Эти изменения не гарантируют определённого прироста FPS и не устраняют
полностью задержки первой компиляции шейдеров. Доступность возможностей
зависит от GPU и приложения.

## Состояние поддержки гарнитур

| Гарнитура | Состояние в универсальном приложении |
| --- | --- |
| Quest 3 | Исторические проверки v907, последующие GPU-тесты MSAA2/VRS и приёмка Quest demo; подробности в описании вариантов |
| PICO 4 | Работа исправления в отдельной v891 подтверждена ранее; текущая универсальная сборка требует проверки на устройстве |
| Quest 2 / Quest Pro | Целевые модели универсальной сборки; проверка на устройствах ещё требуется |
| PICO 4 Ultra | Целевая модель; текущая универсальная сборка требует проверки на устройстве |

Приложение распознаёт закреплённые варианты Turnip Adreno 650 и 740/740v3.
Таблица описывает **интеграцию с приложением**, а не совместимость отдельной
библиотеки с любым Vulkan-приложением. Короткие проверки Quest 3 не заменяют
длительную игру, проверку нагрева и всех режимов управления.

## Варианты драйвера — 17.10.2026

| Вариант | Библиотека | Назначение |
| --- | --- | --- |
| `compat` (по умолчанию) | [Прежняя совместимость](prebuilt/android-arm64/libalyx_turnip.so) | Исходный драйвер v907, сохранён без изменений |
| `msaa-vrs` | [MSAA2 + VRS](prebuilt/android-arm64/msaa-vrs/libalyx_turnip.so) | Проверен на Quest; выбран универсальным сборщиком 0.185 |
| `msaa-vrs-cache` | [Кэш итоговой карты](prebuilt/android-arm64/msaa-vrs-cache/libalyx_turnip.so) | Тестовая/demo-интеграция Quest, не публичный универсальный пресет |

Выбор `msaa-vrs` универсальным сборщиком не означает проверку на всех гарнитурах.
PICO и Quest 2/Pro требуют отдельных проверок совместимости. Вариант с новым
кэшем прямо исключён из публичных, универсальных и PICO-сборок проверками
приложения. [Подробности и полные контрольные суммы](docs/VARIANTS.md).

## Драйвер и исходники

Эталонная библиотека: [`prebuilt/android-arm64/libalyx_turnip.so`](prebuilt/android-arm64/libalyx_turnip.so).
Она побайтово совпадает с `libquest3turnip.so` из универсальной v907;
изменено только имя файла.

```text
SHA256 1559bf7493ae397c274c9743befcbcc4bd6cfd6e1232f4f41f0f45e5374c25bb
```

Исходники представлены как **закреплённая база Mesa и полный набор патчей**,
включая профиль PGO и исходные манифесты сборки. `scripts/build.py`
загружает либо читает точный архив Mesa, проверяет контрольную сумму
и восстанавливает полное дерево исходников перед компиляцией.
Большое дерево upstream Mesa не дублируется в Git.

```sh
python3 scripts/verify.py
python3 scripts/build.py --variant msaa-vrs --out /tmp/alyx-turnip-source --prepare-only
```

Для подготовки исходников нужны Linux/WSL, Python 3.12+ и Git. Полная сборка
описана в [двуязычной инструкции](docs/BUILD.md#русский).

## Интеграция

Драйвер загружается внутри приложения и не устанавливается как системный
драйвер Android. Хост Alyx использует свой загрузчик и соответствующие
настройки импорта изображений и гарнитуры. Хост и слой импорта — отдельный
компонент, который не входит в этот репозиторий драйвера.

При подключении пересобранной библиотеки сохраняйте ожидаемое приложением
имя файла и обновляйте его закреплённые контрольные суммы. Название
репозитория не меняет Vulkan-имена устройств и внутренние идентификаторы.
Перед заменой рабочей библиотеки новую сборку нужно проверить на устройстве.

## Структура

| Путь | Содержимое |
| --- | --- |
| `patches/` | Полный набор базовых изменений Quest относительно закреплённой Mesa |
| `tests/turnip_*` | Патчи драйвера, исходники VRS и проверка его CPU-политики |
| `dependencies/` | Профиль компилятора, генератор патча и исторические входы сборки |

| `provenance/` | Ревизии, контрольные суммы и записи предыдущих проверок |
| `licenses/` | Сохранённые тексты лицензий upstream |
