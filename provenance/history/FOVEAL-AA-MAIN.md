# MSAA 2× + FDM + центральный TAA

Принятый на Quest режим из v2069 сохранён в main. Сборка
`./build-main-demo.ps1 -VersionCode 2070` добавляет его первым пунктом
сглаживания вместе со всеми прежними вариантами. VRS должен быть включён.

У нового режима собственный ID `msaa_fdm_taa` и библиотека
`alyxhost_aa_foveal_taa`. Прежние ID, библиотеки и параметры SMAA/TAA
сохранены: `smaa_depth_temporal` снова означает обычный TAA с глубиной
в односэмпловом рендере. При обновлении тестового v2069 нужно один раз
выбрать новый первый пункт. Сохранённый выбор других режимов не меняется.

В APK четыре рендера: без AA, MSAA 2×, прежний SMAA/TAA и новый
MSAA 2× + FDM + центральный TAA. Каждый имеет собственный каталог;
одинаковый архив рецептов хранится в одном экземпляре. Сборка проверяет
соответствие библиотек, количества сэмплов, профилей и каталогов.

Новый пункт показывается только при наличии `fovealTaaSettings=1`, который
сборщик выставляет для пакета с отдельной библиотекой. Старые APK и
универсальные/PICO-пресеты не получают ссылку на отсутствующий рендер.
Проверенный кэш VRS и освобождение нулевых страниц Steam Audio включены
в сборщике main demo; публичный универсальный пресет пока не изменён.

Проверки v2069: полная сборка и подпись, три исходных каталога, семь локальных
наборов native-тестов; установка на Quest и загрузка `s0/quick01` при 100%
без DRS. Журнал подтвердил MSAA 2×, FDM и валидную историю TAA, пользователь
принял изображение. Дополнительная библиотека возвращает прежние режимы,
не изменяя принятый алгоритм центрального TAA.
