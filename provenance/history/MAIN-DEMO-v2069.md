# Alyx Jailbreak — main demo v2069

Тестовая сборка для Quest на основе `main` (`4bbaf53`).

Включено:
- Нативные MSAA 2× + FDM по сцене, TAA только в чёткой области фовеации.
- Кэш конечной карты VRS в проверенном драйвере Turnip.
- Сокращение копирований AA, общие временные изображения и полные истории цвета/глубины обоих глаз.
- Оптимизация чтения дескрипторов и захвата камеры TAA.
- Возврат нулевых страниц Steam Audio BakedPathData при включённой экономии памяти в режиме центрального TAA, с проверками владельца и версии библиотек.

Переключение между «Выключено», «MSAA 2× + FDM» и «MSAA + FDM, TAA в центре (тест)» сохранено. Для проверки центрального TAA включите VRS/FDM; масштаб 100%, динамическое разрешение выключено. Профиль фовеации выбирается отдельно. После изменения настроек перезапустите игру. Это тестовый APK порта; данные самой игры в него не входят.

Новые GPU/CPU-профилировщики и экспериментальный пропуск resolve не включены. Штатный release-пресет автоматически на этот набор не переключён. Код подготовлен в рабочем дереве main без коммита и push.

Повторная сборка из подготовленного checkout:

```powershell
./build-main-demo.ps1 -VersionCode 2069
```

Используйте новый VersionCode для повторного запуска после уже завершённой сборки: сценарии запрещают перезаписывать существующие каталоги результатов.

`apply-package.py` переносит исходники из `overlay/` в чистый checkout указанного main-коммита. Он проверяет исходные и конечные SHA256 и сначала проверяет весь набор. По умолчанию выполняется только проверка:

```text
python apply-package.py --root E:/path/to/main-checkout
python apply-package.py --root E:/path/to/main-checkout --apply
```

Это накладной пакет изменений, а не полный репозиторий: нужны существующие зависимости проекта и штатные Android SDK/NDK/JDK. APK распространяется отдельно как `Alyx-Jailbreak-main-demo-v2069.apk`.

Проверены сборка, подписи APK, три библиотеки рендера, их каталоги, общий драйвер и исходные хеши. Локальные Linux-тесты проверяют камеру, фовеальные области, регистр глубины, очередь изображений и математику TAA. Новый APK на гарнитуре в этом шаге не запускался: Quest недоступен по ADB. Прежние игровые измерения относятся к исходным проверенным изменениям, а не к новому замеру этой сборки. Не заявляется полная предварительная компиляция шейдеров всех уровней.
